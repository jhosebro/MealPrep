# Política de seguridad

## Reportar una vulnerabilidad

No abras un issue público. Usa **GitHub → Security → Report a vulnerability** (reporte privado) en este repositorio.

Incluye: descripción, pasos para reproducir e impacto. Respondemos en un máximo de 5 días hábiles y
coordinamos la divulgación una vez publicado el arreglo.

## Alcance

- App móvil y web de MealPrep (este repositorio).
- Fuera de alcance: servicios de terceros (Supabase, Google, Open Food Facts), salvo un mal uso por nuestra parte.

## Datos personales

Para ejercer tus derechos de acceso, portabilidad o supresión usa **Configuración → Exportar mis datos /
Eliminar mi cuenta** en la app. Detalle de controles: [docs/security/HARDENING.md](docs/security/HARDENING.md).
